# Neon Orbit Android widget

This is a native Android home-screen widget for the PWA at
`https://mukeshmajhi.com.np/`.

Open this `android-widget` folder in Android Studio, let Gradle sync, then run or
build the app. After installing it, long-press the Android home screen, choose
Widgets, and add **Mukesh Majhi — Neon Orbit**. Tapping the widget opens the game.
